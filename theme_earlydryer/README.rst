================
Earlydryer Theme
================

Website theme for EarlyDryer, built from the logo and the copy on
earlydryer.com and from the printed flyers.

**Table of contents**

.. contents::
   :local:

Brand
=====

* Palette *earlydryer*: royal blue ``#0B5EB4`` (primary), sun yellow
  ``#F4C20D`` (secondary), sky ``#EAF4FB``, white, deep navy ``#0A2540``.
  Teal ``#5AB6C4`` from the current site is kept for footer icons.
* Fonts: *Plus Jakarta Sans* for headings and buttons, *Inter* for text.
* Pill buttons, rounded cards, white waves and soap bubbles as on the flyers.

What it sets up
===============

* Logo and favicon of the website (on *Use this theme*).
* Header: default layout with a *Book a Pickup* button to ``/pickup``.
* Menus *Services* and *About us*, anchors on the homepage.
* Homepage: hero, about us, services, how it works, why EarlyDryer,
  coverage and call to action. All sections are plain text blocks, editable
  in the website builder.
* Footer: logo and slogan, phones, email, addresses, hours, links.

Usage
=====

Install, then *Website > Configuration > Settings > Choose a theme* (or the
theme switcher of the website builder) and pick *Earlydryer Theme*.

``/pickup`` comes from ``earlydryer_website_pickup``; without it the header
button leads to a 404. That module also adds its own *Book a Pickup* menu,
which you may hide since the header button does the same.

Applying the theme again resets the homepage to the theme's content; edits
made in the builder are kept otherwise.
